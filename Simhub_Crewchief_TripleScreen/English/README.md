# Le Mans Ultimate + SimHub + CrewChief on Linux (Proton)

# 🇬🇧 English

## What will you find in this folder?

This folder contains a complete guide to installing and configuring **Le Mans Ultimate**, **SimHub**, and **CrewChief** on **Linux** using **Proton**.

It also includes a working configuration for **triple-screen setups on Wayland (KDE Plasma) without Gamescope**, together with the scripts and configuration files used during the installation process.

The goal of this documentation is to provide a single reference containing everything needed to enjoy Le Mans Ultimate on Linux with an experience as close as possible to Windows.

## Contents

This folder includes:

- 📄 Complete Installation Guide (English)
- 📄 Installation scripts
- 📄 Launch scripts
- 📄 Triple-screen configuration files
- 📄 Configuration examples

## What does this guide cover?

The documentation includes:

- Installing Le Mans Ultimate using Proton.
- Installing SimHub.
- Installing CrewChief.
- Telemetry configuration.
- Firewall configuration.
- Triple-screen setup.
- Wayland and KDE Plasma configuration.
- Steam launch option examples.
- Recommended startup and shutdown sequence.

## Tested configuration

- Operating System: CachyOS
- Desktop Environment: KDE Plasma (Wayland)
- Game: Le Mans Ultimate
- Proton: GE-Proton10-34-LMU-hid-fixes
- Triple Screen: 7680×1440 @ 144 Hz
- Wheelbase: Fanatec CSL DD 8 Nm

Although this guide was created using the above configuration, most of the information should also be applicable to other Linux distributions and Proton versions.
