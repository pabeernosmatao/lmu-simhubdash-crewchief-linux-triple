# 🇪🇸 Español

## ¿Qué encontrarás en esta carpeta?

Esta carpeta contiene una guía completa para instalar y configurar **Le Mans Ultimate**, **SimHub** y **CrewChief** en **Linux** utilizando **Proton**.

Además, incluye una configuración para utilizar **tres monitores en Wayland (KDE Plasma) sin necesidad de Gamescope**, así como los scripts y archivos de configuración utilizados durante la instalación.

El objetivo de esta documentación es reunir en un único lugar todo lo necesario para disfrutar de Le Mans Ultimate en Linux con una experiencia lo más cercana posible a la de Windows.

Esta carpeta incluye:

## ¿Qué incluye esta guía?

La documentación cubre los siguientes aspectos:

- Instalación de Le Mans Ultimate mediante Proton.
- Instalación de SimHub.
- Instalación de CrewChief.
- Configuración de la telemetría.
- Configuración del cortafuegos.
- Configuración para tres monitores.
- Configuración para Wayland y KDE Plasma.
- Ejemplos de opciones de lanzamiento de Steam.
- Orden recomendado de inicio y cierre de las aplicaciones.

## Configuración utilizada para las pruebas

- Sistema operativo: CachyOS
- Escritorio: KDE Plasma (Wayland)
- Juego: Le Mans Ultimate
- Proton: GE-Proton10-34-LMU-hid-fixes
- Triple monitor: 7680×1440 @ 144 Hz
- Base: Fanatec CSL DD 8 Nm

Aunque la guía ha sido desarrollada con esta configuración, gran parte de ella debería ser válida para otras distribuciones Linux y diferentes versiones de Proton.
