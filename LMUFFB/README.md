# 🇪🇸 Español

## ¿Qué encontrarás en esta carpeta?

Esta carpeta contiene las guías de instalación de **LMUFFB** para **Le Mans Ultimate** en sistemas **Linux** utilizando **Proton**.

El objetivo es facilitar la instalación y configuración de LMUFFB compartiendo un procedimiento que ha sido probado y funciona correctamente bajo Linux.

### Contenido

- 📄 Guía de instalación en Español.
- 📄 Installation Guide in English.

### ¿Qué es LMUFFB?

**LMUFFB** es un proyecto desarrollado por **coasting-nc** que reemplaza el Force Feedback original de **Le Mans Ultimate** por un sistema mucho más configurable y detallado, permitiendo adaptar la sensación del volante a las preferencias de cada piloto.

Todo el mérito de LMUFFB pertenece a su desarrollador.

## Repositorio oficial

https://github.com/coasting-nc/LMUFFB

Si este proyecto te resulta útil, considera darle una ⭐ al repositorio para apoyar su desarrollo.

### Objetivo de estas guías

Estas guías **no sustituyen la documentación oficial** de LMUFFB.

Su único propósito es mostrar una forma sencilla de instalar y ejecutar LMUFFB bajo Linux utilizando Proton.

### Configuración utilizada para las pruebas

- Sistema operativo: CachyOS
- Juego: Le Mans Ultimate
- Proton: GE-Proton10-34-LMU-hid-fixes
- Base: Fanatec CSL DD 8 Nm

Es posible que otras distribuciones de Linux y versiones de Proton también sean compatibles.

# 🇬🇧 English

## What will you find in this folder?

This folder contains installation guides for **LMUFFB** running with **Le Mans Ultimate** on **Linux** using **Proton**.

The purpose of these guides is to simplify the installation and configuration process by documenting a setup that has been successfully tested under Linux.

### Contents

- 📄 Installation Guide (English)
- 📄 Guía de instalación (Español)

### What is LMUFFB?

**LMUFFB** is a project developed by **coasting-nc** that replaces the original **Le Mans Ultimate** Force Feedback with a much more configurable and detailed system, allowing drivers to fine-tune the steering feel to their personal preferences.

All credit for LMUFFB belongs to its developer.

## Official repository

https://github.com/coasting-nc/LMUFFB

If you enjoy using LMUFFB, please consider giving the project a ⭐ on GitHub to support its development.

### Purpose of these guides

These guides are **not intended to replace the official LMUFFB documentation**.

Their purpose is simply to document one proven method of installing and running LMUFFB under Linux using Proton.

### Tested configuration

- Operating System: CachyOS
- Game: Le Mans Ultimate
- Proton: GE-Proton10-34-LMU-hid-fixes
- Wheelbase: Fanatec CSL DD 8 Nm

Other Linux distributions and Proton versions may also work.
